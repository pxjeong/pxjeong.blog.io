# Px. · 기록의 수조

정보보안공학과 블로그와 포트폴리오입니다. 공개 티스토리 RSS로 글 목록과 미리보기를 구성합니다. 목록에서 티스토리 글을 누르면 사진과 서식이 포함된 원문으로 바로 이동합니다. 글 한 편당 주제에 맞는 물고기 한 마리가 생성됩니다.

## 로컬에서 보기

저장소 루트에서 서버를 실행하세요. Python 표준 라이브러리만 사용합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요. 방문할 때 먹이가 떨어지고 **먹이 주기** 버튼으로 추가할 수 있습니다. 먹이를 물고기 입까지 끌면 물고기가 먹습니다. 키보드로는 수조에 포커스를 두고 **F**를 눌러 한 알을 줄 수 있습니다. 물고기는 저장된 먹이 횟수에 따라 처음 크기보다 최대 약 25% 커집니다. 방문 및 성장 기록은 브라우저별로 저장됩니다. 글이 비어 있는 동안은 수조에 예시 물고기가 표시됩니다.

## GitHub Pages와 티스토리 연결

1. 이 저장소의 `main` 브랜치에 파일을 올립니다.
2. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. 티스토리에서 공개 RSS를 사용할 수 있는지 확인합니다. GitHub의 **Actions → Blog and Tistory RSS → Run workflow**를 실행하면 첫 가져오기와 배포를 함께 시도합니다.
4. 이후 GitHub Actions가 약 30분 간격으로 공개 RSS를 확인합니다. GitHub의 예약 실행은 지연될 수 있습니다. 페이지 주소는 배포 후 **Settings → Pages**에서 확인할 수 있습니다.

가져온 글은 `data/tistory.json`에 보관합니다. 이후 글이 RSS의 최근 목록에서 빠져도 보관본에 남습니다. RSS에 없는 과거 글은 직접 추가할 수 있습니다. 티스토리에서 글을 비공개로 바꾸거나 삭제한 경우 보관본에서도 해당 항목을 제거하세요. 주제는 RSS 카테고리 이름을 우선으로 분류합니다. 카테고리로 분류할 수 없는 경우 제목에 ‘논문 리뷰’처럼 명시된 글은 **논문/컨퍼런스**에, 나머지는 **블로그/기술문서**에 표시합니다.

## 글과 포트폴리오 업데이트

GitHub에서 직접 글을 쓰려면 `data/posts.json`에 항목을 추가하세요. `id`는 글마다 고유하게 유지하면 물고기의 성장 기록도 유지됩니다. `body`는 일반 텍스트입니다.

```json
[
  {
    "id": "first-post",
    "title": "첫 번째 개발 기록",
    "category": "dev",
    "date": "2026-11-24",
    "body": "글 내용을 여기에 적습니다."
  }
]
```

| category | 주제 |
| --- | --- |
| `dev` | 개발 |
| `ctf` | CTF/Wargame |
| `bounty` | Bug Bounty |
| `docs` | 블로그/기술문서 |
| `research` | 논문/컨퍼런스 |
| `awards` | 공모전/자격증 |

포트폴리오 소개와 링크는 `index.html`의 `portfolio` 섹션에서 수정할 수 있습니다.
